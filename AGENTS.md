# Project
Personal About Me website for Rinku, an MSc student at SDU.
Plain HTML and CSS only. Published with GitHub Pages from the docs folder.
Site file: docs/index.html (CSS is in a <style> block inside this file).

## Current state
Sections: header, About Me, Education, Interests & Hobbies, Contact, footer.

## Conventions
- Use plain HTML and CSS only. Never add React, Tailwind, JavaScript frameworks or libraries.
- Keep all website files inside the docs folder.
- Put each new section in a <section> with a <div class="card"> inside, like the existing ones.
- Keep the existing colours: dark blue #0a2f6b for headings, #333 for text, #f4f8fc for light backgrounds.
- Keep the font Arial, Helvetica, sans-serif.
- Use 4-space indentation, matching the existing file.
- Add a short CSS comment above any new CSS block.

## Do not
- Do not change existing text unless asked.
- Do not put notes, plans or personal files in the docs folder (it is public).
- Do not add API keys, passwords or personal contact details.
